\chapter{Aanvullende functionaliteiten}%
\label{ch:aanvullende-functionaliteiten}

Dit hoofdstuk bespreekt e-mailnotificaties, bijlagen en documentatie. De gewone README beschrijft hoe het project gestart wordt; de technische README licht architectuur, workflows en keuzes toe.

\section{E-mailnotificaties met Brevo}

Wanneer een administrator antwoordt of een status wijzigt, krijgt de klant een e-mail. De backend gebruikt hiervoor Brevo, een provider voor transactionele berichten~\autocite{BrevoApiDocs2026}. \texttt{TicketService} beslist wanneer een notificatie nodig is; \texttt{EmailService} bouwt en verstuurt de e-mail. Zonder Brevo API-sleutel wordt alleen een waarschuwing gelogd, zodat lokale ontwikkeling blijft werken.

\section{Bijlagen en uploadlimiet}

Bijlagen kunnen toegevoegd worden bij ticketcreatie en bij antwoorden. De frontend gebruikt Expo DocumentPicker en toont hoeveel van de 20~MB selectielimiet al gebruikt is. De backend controleert bestandstype en grootte opnieuw. Bestanden worden lokaal op de API-server opgeslagen; de databank bewaart metadata zoals bestandsnaam, contenttype, relatief pad, ticket en bericht. Afbeeldingen krijgen een preview in de conversatie, zodat screenshots meteen bekeken kunnen worden.
