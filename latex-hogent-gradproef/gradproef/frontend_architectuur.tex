\chapter{Frontendarchitectuur en gebruikersinterface}%
\label{ch:frontendarchitectuur}

De frontend is gebouwd met Expo React Native en opgesplitst in schermen, hooks, componenten, API-modules, validatie, stijlen en hulpfuncties.

\section{Schermen, hooks en componenten}

Schermen bepalen wat zichtbaar is. Hooks beheren gedrag zoals laden, zoeken, filteren en pagineren. Componenten vormen herbruikbare UI-blokken. API-modules communiceren met de backend.

\section{Dashboardlogica}

De dashboards bewaren de ruwe tickets als bron van waarheid. Daarna worden zoekresultaten, filters, statusgroepen, tellingen en pagina's afgeleid. Dit vermindert de kans op inconsistente lijsten. Als de ruwe ticketlijst verandert, worden de afgeleide resultaten opnieuw berekend.

Conceptueel vertrekt de dashboardlogica van ruwe data en loopt ze daarna via zoeken, filters, statusgroepen en paginatie.

\section{Paginatie en hergebruik}

Paginatie is gecentraliseerd in \texttt{usePagination}. De generieke hook werkt voor tickets, gesprekken en klantenlijsten, zodat dezelfde logica niet op meerdere plaatsen terugkomt.

\begin{listing}[H]
\begin{minted}[fontsize=\scriptsize,baselinestretch=0.9]{typescript}
export function usePagination<T>(
  items: T[],
  { pageSize, initialPage = "first", resetKey }: UsePaginationOptions,
) {
  const totalPages = Math.max(1, Math.ceil(items.length / pageSize));
  const [currentPage, setCurrentPage] = useState(1);

  const pageItems = useMemo(
    () => items.slice(startIndex, endIndex),
    [endIndex, items, startIndex],
  );

  return { pageItems, currentPage, totalPages };
}
\end{minted}
\caption[Generieke paginatiehook]{Vereenvoudigd voorbeeld van de generieke paginatiehook.}
\label{lst:usepagination}
\end{listing}

\section{Ticketgroepen en conversatie}

De klant- en adminpagina's gebruiken statusgroepen voor \texttt{New}, \texttt{Open} en \texttt{Closed}. \texttt{TicketGroupSection} toont een groep tickets en gebruikt intern dezelfde paginatiehook. Elke groep heeft eigen paginatie.

In het ticketdetail staan adminberichten en klantberichten aan verschillende kanten met een andere achtergrondkleur. Daardoor blijft een lange conversatie overzichtelijker.
